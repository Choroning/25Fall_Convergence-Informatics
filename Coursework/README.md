| [Exam_Final](Exam_Final/) | Own answer R code for the week 16 final exam (practical). It finds the clustering with the highest Silhouette score through a two-stage search over PCA representations, distance metrics, and algorithms (Q1), visualizes it as a PC1-PC2 scatter plot (Q2), and interprets the clusters by clinical variables with univariate tests, Random Forest importance, and post-hoc pairwise comparisons (Q3). With PCA-reduced sensor features and clinical features, it compares race classification models (Glmnet, Random Forest, multinomial logistic regression, SVM, Q4) and FEV1 regression models (Elastic Net, Random Forest, GBM, SVM, Q5), and `Final_JT.R` checks the dimensions, columns, and missing values of the exam data. It connects to Chapters 3-6, and the exam data are restricted and not included | [R code](Exam_Final/) |
| [HW02_Unsupervised-Learning](HW02_Unsupervised-Learning/) | R solutions of assignment 2, given in week 13. They visualize gene expression data by disease (original and filtered data) with PCA, t-SNE, and UMAP (Q1), and perform hierarchical clustering with Ward's method (Q3) and a search for the optimal K of K-means by Silhouette score (Q4). They build and visualize linear regression models from the weight loss data of a professor and a student (Q6, Q8), predict their weights on 2021-11-22 and 2022-11-23, and analyze the reliability of long-term predictions (Q7, Q9). It connects to Chapter 3 (Unsupervised Learning), Chapter 4 (Dimension Reduction and PCA), and Chapter 5 (Modeling) | [R code](HW02_Unsupervised-Learning/Solution/) |
| [HW03_Supervised-Learning](HW03_Supervised-Learning/) | R solutions of assignment 3, given in week 14. They classify asthma vs. control with a LOOCV pipeline of limma feature selection, SMOTE oversampling, and a PAMR classifier (Q1), visualize COVID-19 data with PCA, t-SNE, and UMAP (Q2-1), and compare nine models (logistic regression, LDA, QDA, kNN, naive Bayes, linear SVM, RBF SVM, Random Forest, GBM) with repeated 10-fold cross-validation by accuracy (Q2-2) and sensitivity (Q2-3). They identify a serial killer suspect in a DNA marker database with Hamming distance, Euclidean distance, and PCA visualization (Q3). It connects to Chapter 3 (Unsupervised Learning), Chapter 4 (Dimension Reduction and PCA), and Chapter 6 (Supervised Learning) | [R code](HW03_Supervised-Learning/Solution/) |
| [Lab03_Unsupervised-Learning](Lab03_Unsupervised-Learning/) | Lab code organized from the unsupervised learning demonstration code of weeks 10-11. It covers hierarchical clustering, K-means clustering with silhouette analysis, and dimension reduction and visualization with PCA, t-SNE, and UMAP, and connects to Chapter 3 (Unsupervised Learning) and Chapter 4 (Dimension Reduction and PCA). The lab data (`Elite Sports Cars in Data.csv`) are not included | [Lab_UnsupervisedLearning.R](Lab03_Unsupervised-Learning/Lab_UnsupervisedLearning.R) |
| [Lab05_Modeling](Lab05_Modeling/) | Lab code organized from the linear regression demonstration code of week 12 (11/19). It fits a linear regression model to diet data (`DietData_v1.csv`) and draws ggplot2 visualizations and diagnostic plots, and connects to Chapter 5 (Modeling) | [Lab_LinearRegression.R](Lab05_Modeling/Lab_LinearRegression.R) |
| [Lab06_Supervised-Learning](Lab06_Supervised-Learning/) | Lab code organized from the supervised learning demonstration code of week 14 (12/3). `Lab_SupervisedLearning.R` covers decision tree classification, a cross-validated comparison of LDA, QDA, and SVM, and a custom KNN implementation, and `Lab_KNN-CrossValidation.R` implements a Euclidean distance function and a majority-vote KNN classifier from scratch and evaluates fold-wise accuracy with stratified K-fold cross-validation. It connects to Chapter 6 (Supervised Learning) | [Lab_SupervisedLearning.R](Lab06_Supervised-Learning/Lab_SupervisedLearning.R), [Lab_KNN-CrossValidation.R](Lab06_Supervised-Learning/Lab_KNN-CrossValidation.R) |

The data for the assignments and labs are in the `data/` folder of each item: [`HW02_Unsupervised-Learning/data`](HW02_Unsupervised-Learning/data/) for assignment 2, [`HW03_Supervised-Learning/data`](HW03_Supervised-Learning/data/) for assignment 3, and [`Lab05_Modeling/data`](Lab05_Modeling/data/) for the linear regression lab.
