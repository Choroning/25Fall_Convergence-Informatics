## 데이터와 불러오기

LMS에서 내려받은 압축 파일을 풀면 데이터 파일 세 개가 있다. 이 레포지토리에서는 과제 폴더의 [`data/`](../data/)에 있다.

| 파일 | 내용 | 쓰는 문제 |
|:-----|:-----|:-----|
| `1.Homework2_OriginalData.tsv` | 질병 7개의 환자 21명(질병마다 3명)에 대해 특징 16,273개를 측정한 유전자 발현 데이터. 첫 열 `sampleName`은 `COVID19_Patient1`처럼 질병 이름과 환자 번호로 이루어진 샘플 이름이다 | 문제 1~5 |
| `2.Homework2_FilteredData.tsv` | 같은 환자 21명에 대해 특징을 100개로 줄인 유전자 발현 데이터 | 문제 1~5 |
| `HW2_Data3.xlsx` | 교수와 학생의 날짜(`Date`)별 체중(`ProfWeight_Kg`, `StudentWeight_Kg`), 식단, 운동 기록 (2021-06-28 ~ 08-31, 65일) | 문제 6~9 |

*표 1. 과제의 데이터 파일*

두 TSV 파일을 작업 디렉토리(`setwd(XXX)`)에 두고 data.table 패키지의 `fread()` 함수를 다음과 같이 쓰면 데이터를 불러올 수 있다.

```r
library(data.table)

dataOriginal <- data.frame(fread("1.Homework2_OriginalData.tsv",
    sep = "\t", head = T, stringsAsFactor = F))

dataFiltered <- data.frame(fread("2.Homework2_FilteredData.tsv",
    sep = "\t", head = T, stringsAsFactor = F))
```

내려받은 데이터를 RStudio 작업 환경으로 불러오는 방법은 여러 가지이므로, 검색이나 강의 교재(예: [https://rafalab.github.io/dsbook/importing-data.html](https://rafalab.github.io/dsbook/importing-data.html))를 참고하여 여러 방법에 익숙해지기를 권한다. 기말고사도 실기 시험이므로 데이터를 불러오는 방법을 익혀 두어야 한다.

## 문제 1~5: 유전자 발현 데이터

문제 1~5는 `1.Homework2_OriginalData.tsv`나 `2.Homework2_FilteredData.tsv`를 쓴다.

### 문제 1

두 데이터 각각에 PCA, t-SNE, UMAP 분석을 수행한 뒤 처음 두 차원의 벡터를 그려라. 그림을 그릴 때 질병에 따라 다른 색을 칠한다. 질병마다 샘플이 3개씩 있다.

- **제출할 항목:** `dataOriginal`의 PCA, t-SNE, UMAP 그림과 `dataFiltered`의 PCA, t-SNE, UMAP 그림

### 문제 2

두 데이터의 결과 사이에 유의한 차이가 있는가? 그 이유는 무엇인가? 차이가 있다면 어느 데이터를 써야 하는가?

### 문제 3

계층적 군집화로 군집 분석을 수행하라. 차원 축소 결과와 가장 비슷한 형태가 되는 매개변수(거리 척도, 연결법 등)를 찾고, 덴드로그램에서 최적이라고 생각하는 군집 수로 잘라 표시하라.

- **제출할 항목:** 덴드로그램

### 문제 4

유클리드 거리에 기반한 K-평균 군집화로 군집 분석을 수행하라. K를 2부터 10까지 바꾸며 Silhouette 점수를 기준으로 최적의 군집 수 K를 찾고, Silhouette 점수 그림을 그려라.

- **제출할 항목:** K-평균 군집화에 기반한 Silhouette 그림

### 문제 5

위의 모든 분석을 바탕으로, 이 데이터가 말해 주는 바를 정보학자의 관점에서 자유롭게 해석하라. 가능하면 R로 그린 그림을 근거로 설명하며, 분량은 2쪽 이내이다. 어떤 비지도 학습 방법이 좋은지, 몇 개의 군집이 맞는지, 질병 사이의 관계, 질병 예측 모델링의 가능성 등을 다룰 수 있다.

## 문제 6~9: 체중 감량 데이터

문제 6~9는 `HW2_Data3.xlsx`를 쓴다.

### 문제 6

이 데이터는 2021년 여름방학 동안의 체중 감량 기록이다. 교수와 학생의 체중 변화를 각각 예측 모델링하라. 교수와 학생의 데이터에서 세운 최적의 모델은 각각 무엇인가? 또 통계적 추론으로 비교할 때 두 사람 중 누구의 체중 감량 효과가 더 빨랐는가? 반드시 추정된 통계량의 비교로 해석해야 한다.

- **제출할 항목:** 교수의 모델, 학생의 모델, 추정된 모델의 해석

### 문제 7

그 시점부터 오늘(2021-11-22)까지 다이어트를 계속했다면 두 사람의 예측 체중은 얼마인가?

- **제출할 항목:** 2021-11-22의 교수 예측 체중과 학생 예측 체중

### 문제 8

주어진 데이터를 산점도로 시각화하고, 교수와 학생에 대해 추정한 최적의 모델을 서로 다른 색으로 나타내라. 힌트는 [https://rafalab.github.io/dsbook/regression.html](https://rafalab.github.io/dsbook/regression.html)이다.

- **제출할 항목:** 적합된 모델을 함께 그린 산점도

### 문제 9

그 시점부터 2022-11-23까지 다이어트를 계속했다면 두 사람의 예측 체중은 얼마인가?

- **제출할 항목:** 2022-11-23의 교수 예측 체중과 학생 예측 체중, 모델의 해석(1쪽 이내). 해석할 때는 이 결과를 바탕으로 단순 선형 회귀의 잠재적인 함정을 생각해 본다.
