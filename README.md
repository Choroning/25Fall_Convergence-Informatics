## 📝 About This Repository

- `Lecture-Notes/` holds lecture notes that follow the chapter order of the lecture slides (`Ch##`).
- `Coursework/` holds the assignment solutions, the lecture demonstration code, and the final exam R code, with sample datasets in each item's `data/`.
- Every lecture note comes as an English (`.md`) and Korean (`.ko.md`) pair.
- The R code files carry **Doxygen-style headers**.

> **🤖 AI Agent Usage**
> This course encouraged active use of AI tools.
> [Claude Code](https://claude.ai/download) was used to organize and translate the notes and to restructure the repository.

### Course Overview

An interdisciplinary course that introduces informatics across academic and industrial fields from a computing perspective, taught in English with R for data analysis. The instructors, schedule, assessment, course policies, and progress are in the [course information document](Course-Information.md).
